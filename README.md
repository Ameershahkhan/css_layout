# CSS Landing Page

This project is part of 'The Odin Project's Foundations' curriculum. This Project is build after the completion of HTML and CSS. This project helped me improve my CSS styling and HTML structuring skills.

### The Main Concepts I learned:
These are the main concepts that I learned from this project
- Flexbox layout mode
- Arranging elements at a desired position on a webpage
- Understanding of Main vs Cross Axes
- Important flexbox properties (flex-direction, justify-content, align-items, flex-wrap, align-content, gap, align-self)
- responsiveness
